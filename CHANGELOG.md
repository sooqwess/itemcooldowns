# Changelog

## 2.0.0

- Added live ActionBar, BossBar, scoreboard, sounds and particle feedback.
- Added a 45-slot cooldown GUI with a purple/black/gold border, localized status and progress.
- Added English, Russian, German, Spanish, French, Portuguese, Chinese, Japanese, Korean and Ukrainian templates, auto locale selection and explicit locale selection.
- Added an optional built-in PlaceholderAPI expansion.
- Added optional pearl, bow, crossbow, shield, totem and wind-charge rules.
- Preserved per-player/per-material atomic cooldown checks and launch-based trident timing.
- Restored Riptide handling; retained the optional Creative-to-Survival PvP switch.
- Limited blocked feedback to one burst per player per second.
- Added entity-region visual dispatch for Folia and Spigot-compatible ActionBar/metadata/locale calls.
- Added GUI click/drag protection, permission checks and rule-wide multi-material status aggregation.
- Added 11 standalone tracker assertions, a coverage check for all ten locale templates, authentic gameplay captures and offline gallery cards.

Compatibility target: Minecraft 1.21–26.3 and Bukkit-compatible forks. Runtime verification in this delivery is limited to Paper 1.21.11; consult `docs/TESTING.md` before claiming full compatibility.
